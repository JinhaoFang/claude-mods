# 0003: Self-contained mods

The first selection pass found popular, high-star mods that work only with a companion binary their own project ships separately — `zenbu-labs/terminal-browser` (a terminal browser), `tomasz-tomczyk/crit`'s `claude-code-tui` integration (needs the `crit` CLI), `modu-ai/moai-adk`'s `moai-board` (needs the `moai` binary), and `23blocks-OS/ai-maestro`'s `amp-inbox-band` (needs its own `amp-inbox.sh` scripts) — and nothing in the inclusion bar spoke to that, so whether such a mod was refused depended on luck. Third-party mods must therefore be **self-contained**: the mod folder alone, vendored, must work with only Claude Code installed, with no dependency on a companion binary, CLI, or service that the upstream project ships separately. General-purpose bases any machine already has (`git`, `node`) do not count against the rule; the line is between a base already present and a companion the upstream project exists to distribute. This deliberately excludes those popular mods: a mod that cannot stand on its own is refused on the bar, whatever its stars.
